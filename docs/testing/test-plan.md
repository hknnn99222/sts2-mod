## 零、前置与冒烟（5 分钟）

1. **构建部署**：确认游戏已关闭 → `cd D:\worlk\sts2-mod\GamblerMod && dotnet build`（用 D 盘 dotnet）→ 无错误。
2. 开游戏 → Mod 管理界面：GamblerMod 与 BaseLib 均为已加载。
3. 选赌徒开一局：
   - [ ] 初始遗物 = **幸运筹码**（不是战士的燃烧之血）
   - [ ] 初始金币 148、HP 72、卡组 10 张（4 打击 4 防御 本钱 试手气，**无底注**）
4. 打完第一场普通战斗无报错、无卡死。

**排障**：任何异常先看日志 `%APPDATA%\SlayTheSpire2\logs\godot.log`，搜 `GamblerMod`（每次掷硬币/扣金币都有记录）和 `ERROR`。

## 四·五-B、存钱修复验证（2026-10-21，修复后待验）

> 背景：存钱（获得金币→等量格挡）实测无效——run 级金币钩子不派发给 power，已改为 GamblerHooks 转发（技术设计 §13）。

| # | 步骤 | 预期 |
|---|---|---|
| C1 | 打出存钱（3 能能力），再打出本钱（获得 5 金币） | **金币入账的同时 +5 格挡** |
| C2 | 存钱在场时打 试手气+幸运筹码改币等任何获得金币的效果 | 每一笔金币都给等量格挡（含战斗奖励结算前的最后一笔） |

## 已知简化与偏离（测试时不用报 bug）

1. **底牌**：正面改多抽 1 张（原设计抽到的牌本回合降费）
2. **梭哈**：金币不足判灰按最低 X=1（5 金）计
3. **幸运筹码**：金币足够时自动改币（原设计弹窗询问）
4. **分红**：金币不足 3 时整回合不触发（不做按比例折算）
5. **清台**：永久成长写在卡牌实例的 DamageVar 上——同一次冒险内跨战斗保留；读档后若被重置属引擎序列化限制（验收时顺手读档看一眼）
6. **留一手/换牌**：选卡界面沿用引擎自带的「弃置」提示文案（引擎无"放回抽牌堆"预设提示），实际动作是把牌放回抽牌堆
7. **保本**：触发点接在 Core 的花费记账（只统计卡牌主动花费的金币费；分红之类的被动扣款不计）
8. 全部卡牌立绘为占位图、掷硬币无专门动画（正反面靠特效/音效区分）——美术批统一处理
