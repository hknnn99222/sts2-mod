# 赌徒 Mod 测试文档（M1–M4 全量验收）

> 版本：v0.3.0（43 卡全量）｜日期：2026-10-14｜测试人按章节逐项打勾
> 建议顺序：先跑「零、冒烟」确认没炸，再按章节测。**测完一节汇报一节**，失败的记下卡名和现象。

## 零、前置与冒烟（5 分钟）

1. **构建部署**：确认游戏已关闭 → `cd D:\worlk\sts2-mod\GamblerMod && dotnet build`（用 D 盘 dotnet）→ 无错误。
2. 开游戏 → Mod 管理界面：GamblerMod 与 BaseLib 均为已加载。
3. 选赌徒开一局：
   - [ ] 初始遗物 = **幸运筹码**（不是战士的燃烧之血）
   - [ ] 初始金币 148、HP 72、卡组 10 张（4 打击 4 防御 私房钱 试手气，**无飞牌**）
4. 打完第一场普通战斗无报错、无卡死。

**排障**：任何异常先看日志 `%APPDATA%\SlayTheSpire2\logs\godot.log`，搜 `GamblerMod`（每次掷硬币/扣金币都有记录）和 `ERROR`。

## 已知简化与偏离（测试时不用报 bug）

1. **数牌**：单选弃 1 张（原设计 0-N 多选）——选卡 UI 管线后续接
2. **加注**：自动花满 min(6, 金币)（原设计玩家自选投入额）
3. **底牌**：正面改多抽 1 张（原设计抽到的牌本回合降费）
4. **梭哈**：金币不足判灰按最低 X=1（10 金）计
5. **高利贷**：欠款在下场战斗首次回合开始时扣（原设计战斗开始瞬间）
6. **幸运筹码**：金币足够时自动改币（原设计弹窗询问）
7. 全部卡牌立绘为占位图、掷硬币无专门动画（正反面靠特效/音效区分）——美术批统一处理
