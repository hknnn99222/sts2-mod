# 赌徒 Mod 测试文档（M1–M4 全量验收）

> 版本：v0.5.0（76 卡：起始 2 + 常规 76）｜日期：2026-10-17（v1.8 游玩体验优化批同步）｜测试人按章节逐项打勾
> 建议顺序：先跑「零、冒烟」确认没炸，再按章节测。**测完一节汇报一节**，失败的记下卡名和现象。

## 零、前置与冒烟（5 分钟）

1. **构建部署**：确认游戏已关闭 → `cd D:\worlk\sts2-mod\GamblerMod && dotnet build`（用 D 盘 dotnet）→ 无错误。
2. 开游戏 → Mod 管理界面：GamblerMod 与 BaseLib 均为已加载。
3. 选赌徒开一局：
   - [ ] 初始遗物 = **幸运筹码**（不是战士的燃烧之血）
   - [ ] 初始金币 148、HP 72、卡组 10 张（4 打击 4 防御 本钱 试手气，**无底注**）
4. 打完第一场普通战斗无报错、无卡死。

**排障**：任何异常先看日志 `%APPDATA%\SlayTheSpire2\logs\godot.log`，搜 `GamblerMod`（每次掷硬币/扣金币都有记录）和 `ERROR`。

## 四·五、M5：「风头正盛」倍率系统（v1.6 新增）

| 卡/机制 | 预期 |
|---|---|
| 倍率显示 | 进战斗角色头顶显示 `x1.0`（纯文字徽章） |
| 正面推进 | 打任意赌博牌掷出正面 → 徽章变 `x1.5`；再一张正面 → `x2.0` |
| 反面归零 | 掷出反面 → 徽章**立刻**回 `x1.0`（多掷牌中途反面也立刻归零，后面的正面从 1.0 重累） |
| 跨回合保留 | 第一回合滚到 `x2.5`，第二回合开始仍是 `x2.5`（战斗结束才清） |
| 卡面同步 | 手牌里带「风头正盛」的牌，伤害/格挡数字**随倍率实时变化**（同力量改伤害的表现） |
| 兑现清空 | 打出带词条的牌 → 吃满倍率 → 打完徽章回 `x1.0` |
| 只算赌博牌 | 幸运筹码改币**不涨**倍率；赌神/暗记强制正面**要涨** |
| 收手 / 乘胜 | 1 能；x2.0 时分别给 10 格挡 / 12 伤害 |
| 割禾青 | 0 能；倍率 x1.5 → 抽 3 张（至多 3）；打完清空 |
| 兑现 | 1 能；x2.0 时给 14 金币；卡面数字跟着倍率变 |
| 通杀 | 2能+5金；全体 16 伤 ×倍率 |
| 晒冷 | 3能+15金；50 伤 ×倍率 |
| 追数 | 2能+8金；29 伤 ×倍率；**击杀时倍率不清空**（唯一例外） |
| 割肉 | 1 能；10 格挡 ×倍率，自身失去「倍率×3」生命（x2.0 → 失 6 血） |
| 叠注（改造） | 条件从"上一掷正面"改为 **倍率 ≥1.5**；数值**不乘**、**不清空** |
| 底牌（改造） | 条件从"本回合掷出过正面"改为 **倍率 ≥1.5**；不乘不清空 |
| 同花顺（改造） | 挂「风头正盛」：43 伤 ×倍率、**无额外条件**、打完清空 |
| 改卡演练 | 改 1 张新卡数值 → 只动该卡文件 → 不碰 Core → 重编译生效 |
| 徽章校准 | 进战斗看日志「风头徽章已挂载：全局锚点 (x, y)，偏移 -58」，位置不满意就调 `UI/MultiplierBadge.cs` 的 `HeadOffsetY`（当前 -58，负值往上） |
| 掷币反馈 | 徽章右侧**两态**：未掷过 `—`；**正**（金，倍率+0.5）/ **反**（红，倍率归零）。**幸运筹码改币也显示反、倍率照常归零**（遗物只保牌效不保连胜）。换战斗自动回 `—` |
| 徽章自证 | 日志应出现「**徽章帧回调已启动（ProcessFrame 信号）**」+ 一串「徽章刷新 → x1.5 / x2.0」；缺前者=刷新没挂上，缺后者=没掷币 |
| 倍率轨迹对账 | 掷硬币日志带倍率：`掷硬币 X：正面（风头 x1.5）`、幸运筹码改币会标「改币不计」 |

> 注：「兑现」的卡面金币数 **v1.8 起显示当前倍率下的实际到账值**（`MultiplierAwareVar`，x2.0 时卡面就写 14）——金币仍没有带 cardSource 的钩子、只能卡内自算，但卡面不再显示裸值。
> **v1.8 起徽章可悬停**：鼠标停在头顶「倍率 + 正/反」上会弹出提示「掷出正面时倍率增加；掷出反面时倍率清零。」（`Pass` 热区，不影响点角色）。
