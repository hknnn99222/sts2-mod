# 跟你唠个点子：杀戮尖塔2 赌徒 Mod

兄弟，我最近在整一个杀戮尖塔2的 mod，角色是个赌徒，越琢磨越觉得有东西，跟你分享一下。

核心就一句话：钱能直接当战斗力花。他的牌好多是"1 能量 + 5 金币"这种混合费用，多贴点金币就能打出超模效果。关键这钱不是什么战斗专用代币，就是你背包里那袋真金币，商店买卡删卡用的也是它。所以每打出一发金币技能，都在啃自己的购物预算：是当场变强，还是忍住进商店剁手？全程都在做这道题，这就是这角色的魂。

然后是"赌博"词条：牌打出去先掷枚硬币，正面效果加强，反面维持原样，反正不亏，纯看脸的刺激。脸黑也别慌，这角色一堆做局手段——暗记、手气正旺、赌神，初始遗物更是直接让你掷出反面后花钱改成正面。运气不好？砸钱买。手气不行钞票凑，这就是赌徒的浪漫。

玩法路线也多：想爽就走梭哈流，大把金币砸出去换巨炮；想稳就专心做局，把随机硬生生玩成确定；还有几张真赌牌，反面带惩罚的那种，赌性大的直接上。卡池里产金路子也不少，战斗里现金流能自己转起来。

对了，卡牌数量、稀有度、类型比例一开始是照着原版角色的模板配的（20 普 / 35 罕 / 25 稀，共 80 张），后来砍掉了 4 张"一次打出要掷好几枚硬币"的牌，现在 **76 张（20 普 / 33 罕 / 23 稀）**——顺手把「赌博」「风头正盛」做成了真词条，鼠标停在牌上就能看说明。
