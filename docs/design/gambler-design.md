## 2. 核心机制规则

### 2.1 混合费用（角色范式）

- 牌面并列印"X 能量 + Y 金币"，打出时**同时**支付两者；金币不足则不可打出（视同能量不足变灰）。
- 双费卡的效果按**能量档越一级**：`1 能 + 7 金 ≈ 2 能量档效果`；`2 能 + 7 金 ≈ 3 能量档效果`。
- **能量↔金币换算（v1.5）**：`1 能量 = 7 金币`——本角色能量与金币的统一换算率，取代原先按稀有度分档的补贴口径（普 4-6 / 罕 5-10 / 稀 8-15 金 ≈ 1 能量档）。产金卡按其能量费折算金币产出，双费卡的金费补贴亦以该基准为参照。
- **统一金币汇率（v1.4）**：超基线收益 = 金费 × **2.1 伤害**（基线每能量 6 伤）或 × **2.5 格挡**（基线每能量 5 挡）。原版金印"3 金 = 1 能量"（≈2 伤/金，每回合限次的优惠价）为市场上限锚点；赌博卡在新白板基准（含金币换算）上保持期望锚定 E=1.2×；抽牌按 1 抽 ≈ 4 伤效、debuff 近似折算；产金引擎卡不适用战斗汇率。
- "本回合已花费金币"是可追踪量（挥金协同的依据），战斗开始时归零。

### 2.2 赌博（签名词条）

- **触发**：打出带有赌博词条的牌时，在结算前掷一枚硬币。
- **结果**：正面 → 强化效果；反面 → 基础效果。**默认无惩罚**（纯上行方差）。
- **与倍率的联动（v1.6）**：掷出**正面**还会推进「风头正盛」倍率 +0.5；反面在归零之外无额外惩罚（详见 §2.8）。
- **概率**：默认 50/50。正面率修正为**加法叠加，上限 75%**（例：手气正旺 +15%）。"必为正面"类效果无视上限。
- **期望锚定（数值总纲）**：50/50 下，赌博牌期望 = 同费白板 × **1.2**——反面（基础）≈ 白板 × 0.8（牌效弱），正面 = 反面 × 2 ≈ 白板 × 1.6（赌博成功加强）。正面率为 p 时期望倍率 = **0.8 + 0.8p**（65% → 1.32×、75% 上限 → 1.40×、赌神 → 1.6×），这就是做局流的核心回报公式。真赌牌同样按 1.2× 期望折算（反面惩罚计入期望）。逐卡对账见 §5.4。
- **多次赌博 / 连锁**（豹子、俄罗斯轮盘、老虎机 / 连胜）：逐次独立结算，每次均可被做局效果单独干预；连锁类设连锁上限，防止与"赌神"组合成无限循环。
- **时点**：赌博在牌效果结算前完成，结果可见后再决定是否用做局工具（初始遗物为"事后改"）。
- 联机兼容注记：赌博使用玩家独立 RNG（实现期对接 `PlayerRng`）。

### 2.3 做局（操纵硬币）

| 工具 | 来源 | 方式 |
|---|---|---|
| 幸运筹码（初始遗物） | 遗物 | 事后改一掷为正面，每回合 1 次 |
| 暗记 | 罕见技 | 下一次赌博必为正面 |
| 手气正旺 | 罕见能力 | 正面率 +15%（常驻） |
| 赌神 | 稀有能力 | 所有赌博视为正面 |

### 2.4 真赌牌（罕见于稀有大档）

反面带惩罚、正面超大收益的变体，仅 3 张，全部稀有：孤注一掷、俄罗斯轮盘、单双。这是牌池中仅有的"反面更糟"的牌。

### 2.5 产金与经济画像

- **即时产金牌 10 张**（5-18 金/次小额高频；v1.2 新增清台/兑筹/高利贷，v1.5 全线上调）+ **引擎型产金能力 3 张**（返水 / 台规 / 利滚利）。
- **头奖卡 2 张**：老虎机（期望 ≈14 金）、爆机（击杀 +25 金）——大额产金彩蛋。
- **经济画像：小幅战斗盈利**——战斗总产金 + 胜利奖励略高于战斗总支出，每场净盈余目标 +5~15 金，跑图略富但不失控。
- 粗算锚点（第一幕普怪，5 回合）：双费卡打出约 4 次 × 5 金 + 遗物改币 2 次 × 5 金 ≈ 支出 30 金；产金端 本钱 5 + 筹码 7 + 胜利奖励 15 ≈ 收入 27-32 金，构筑成型后靠派彩/抽头/引擎转正为小幅盈利。

### 2.6 debuff 方向

标准 debuff 库（易伤 / 虚弱 / 力量-）+ 金币附加费记法："花费 X 金币：额外施加…"。偷窃 / 勒索 / 赏金类牌直接写"获得 X 金币"当皮，**不自造敌人金币系统**。

### 2.7 升级约定

- **双费卡**：升级优先"-2~3 金币"或增强效果，原则上不降能量费用（金币成本是身份）。
- **赌博卡**：基础与正面同步增强，升级后仍锚定 1.2× 期望（对齐升级档白板；例：试手气 5/10 → 7/14）。
- 升级不改变卡的机制结构（不新增/移除赌博或双费），遵循原版升级惯例。

### 2.8 「风头正盛」倍率系统（v1.6，第二签名词条）

**一句话**：角色头顶浮动徽章显示**倍率**（初始 x1.0）；每次赌博掷出正面 **+0.5**；掷出反面**立刻归零**；带**「风头正盛」**词条的牌数值**乘以倍率**，**结算后倍率清空**——倍率是"可攒可花"的资源，不是被动累积。

| 项 | 规则 |
|---|---|
| 成长 | 每次掷硬币**正面** +0.5，所有牌统一步长；**只算带「赌博」词条的牌**；多掷牌（豹子/老虎机/连胜各 3 掷）**逐次独立计**；真赌牌也算 |
| 做局互动 | 赌神 ✅ 算、暗记 ✅ 算（允许无限滚）；**幸运筹码改币 ❌ 不算 —— 倍率照常按反面归零**（遗物只保牌效、不保连胜，2026-10-16 用户拍板；徽章显示「反」） |
| 归零 | 掷出反面**立刻**归零（多掷牌中途反面 → 归零后从 1.0 重新累）；**战斗内跨回合保留**；战斗结束时清空 |
| 兑现清空 | 「风头正盛」牌**结算后**清空回 1.0（该牌自己吃满倍率）；唯一例外：「追数」击杀时保留 |
| 乘哪些数值 | **伤害 / 格挡 / 金币**（卡面预览实时跟随）；**向上取整**；**不设上限** |
| 词条互斥 | 「风头正盛」牌**不能**同时带「赌博」 |
| 定价 | **裸值 = 白板**（x1.0 时不亏），倍率是纯奖励层 |
| 显示 | 角色**头顶浮动徽章**，纯文字 `x2.5`（美术后补） |

**已知风险（用户已明确接受，勿再劝阻）**：金币 × 倍率 + 不设上限 + 赌神可无限滚 → 理论上可无限刷金币（而金币**跨战斗永久**），经济可被击穿。用户选择不封顶。另：**裸值 = 白板** 意味着这 9 张牌"不赌也不亏、赌赢就是白赚"，卡池整体强度随之上移。

### 7.2 赌徒的战斗现金流（目标画像：小幅盈利）

| 阶段 | 支出预期/场 | 产金预期/场 | 净额 |
