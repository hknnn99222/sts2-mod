1. **金币是第二费用系统**——与商店互通的真金币，牌面直接印"能量 + 金币"混合费用，花金币换越级效果。钱花在变强还是攒着进店，每一场都在博弈。

## 2. 核心机制规则

### 2.1 混合费用（角色范式）

- 牌面并列印"X 能量 + Y 金币"，打出时**同时**支付两者；金币不足则不可打出（视同能量不足变灰）。
- 双费卡的效果按**能量档越一级**：`1 能 + 7 金 ≈ 2 能量档效果`；`2 能 + 7 金 ≈ 3 能量档效果`。
- **能量↔金币换算（v1.5）**：`1 能量 = 7 金币`——本角色能量与金币的统一换算率，取代原先按稀有度分档的补贴口径（普 4-6 / 罕 5-10 / 稀 8-15 金 ≈ 1 能量档）。产金卡按其能量费折算金币产出，双费卡的金费补贴亦以该基准为参照。
- **统一金币汇率（v1.4）**：超基线收益 = 金费 × **2.1 伤害**（基线每能量 6 伤）或 × **2.5 格挡**（基线每能量 5 挡）。原版金印"3 金 = 1 能量"（≈2 伤/金，每回合限次的优惠价）为市场上限锚点；抽牌按 1 抽 ≈ 4 伤效、debuff 近似折算；产金引擎卡不适用战斗汇率。
- "本回合已花费金币"是可追踪量（挥金协同的依据），战斗开始时归零。

### 2.2 赌博（签名词条）

- **触发**：打出带有赌博词条的牌时，在结算前掷一枚硬币。
- **结果**：正面 → 强化效果；反面 → 基础效果。**默认无惩罚**（纯上行方差）。
- **与倍率的联动（v1.6）**：掷出**正面**还会推进「风头正盛」倍率 +0.5；反面在归零之外无额外惩罚（详见 §2.8）。
- **概率**：默认 50/50。正面率修正为**加法叠加，上限 75%**（例：手气正旺 +15%）。"必为正面"类效果无视上限。
- **多段命中 ≠ 多次赌博**：全池每张赌博牌**只掷一次硬币**，结果决定整张牌的效果（俄罗斯轮盘/摇骰的"多段"是同一次掷币的多发命中）。原来的"自掷硬币 + 逐击/连锁"形态（豹子/老虎机/连庄/连胜）已在 v1.8 整体删除——自掷牌挂不上「赌博」词条，还会在一次出牌里多次推进倍率、覆盖徽章正反。
- **时点**：赌博在牌效果结算前完成，结果可见后再决定是否用做局工具（初始遗物为"事后改"）。
- 联机兼容注记：赌博使用玩家独立 RNG（实现期对接 `PlayerRng`）。
- **词条化（v1.8）**：「赌博」与「风头正盛」已是**真正的卡牌词条**（注册进 `CardKeyword`），卡面由引擎自动拼出词条名、鼠标悬停卡牌即弹出提示。文案：赌博 =「投一枚硬币，根据硬币正反决定效果。」、风头正盛 =「卡牌数值随倍率变化。」。因此卡描述正文**不再手写**这两个词条名（只保留机制说明）。

### 2.3 做局（操纵硬币）

| 工具 | 来源 | 方式 |
|---|---|---|
| 幸运筹码（初始遗物） | 遗物 | 事后改一掷为正面，每回合 1 次 |
| 暗记 | 罕见技 | 下一次赌博必为正面 |
| 手气正旺 | 罕见能力 | 正面率 +15%（常驻） |
| 赌神 | 稀有能力 | 所有赌博视为正面 |

### 2.4 真赌牌（罕见于稀有大档）

反面带惩罚、正面超大收益的变体，仅 3 张，全部稀有：孤注一掷、俄罗斯轮盘、单双。这是牌池中仅有的"反面更糟"的牌。

### 2.5 产金与经济画像

- **即时产金牌 10 张**（5-18 金/次小额高频；v1.2 新增清台/兑筹/高利贷，v1.5 全线上调）+ **引擎型产金能力 3 张**（返水 / 台规 / 利滚利）。
- **头奖卡 1 张**：爆机（击杀 +25 金）——大额产金彩蛋（原并列的「老虎机」随 v1.8 删自掷牌一并退场）。
- **经济画像：小幅战斗盈利**——战斗总产金 + 胜利奖励略高于战斗总支出，每场净盈余目标 +5~15 金，跑图略富但不失控。
- 粗算锚点（第一幕普怪，5 回合）：双费卡打出约 4 次 × 5 金 + 遗物改币 2 次 × 5 金 ≈ 支出 30 金；产金端 本钱 5 + 筹码 7 + 胜利奖励 15 ≈ 收入 27-32 金，构筑成型后靠派彩/抽头/引擎转正为小幅盈利。

### 2.6 debuff 方向

标准 debuff 库（易伤 / 虚弱 / 力量-）+ 金币附加费记法："花费 X 金币：额外施加…"。偷窃 / 勒索 / 赏金类牌直接写"获得 X 金币"当皮，**不自造敌人金币系统**。

### 2.7 升级约定

- **双费卡**：升级优先"-2~3 金币"或增强效果，原则上不降能量费用（金币成本是身份）。
- **赌博卡**：基础与正面同步增强（例：试手气 5/10 → 7/14）。
- 升级不改变卡的机制结构（不新增/移除赌博或双费），遵循原版升级惯例。

### 2.8 「风头正盛」倍率系统（v1.6，第二签名词条）

**一句话**：角色头顶浮动徽章显示**倍率**（初始 x1.0）；每次赌博掷出正面 **+0.5**；掷出反面**立刻归零**；带**「风头正盛」**词条的牌数值**乘以倍率**，**结算后倍率清空**——倍率是"可攒可花"的资源，不是被动累积。

| 项 | 规则 |
|---|---|
| 成长 | 每次掷硬币**正面** +0.5，所有牌统一步长；**只算带「赌博」词条的牌**；真赌牌也算（v1.8 起每张牌只掷一次，不再有"多掷逐次计"） |
| 做局互动 | 赌神 ✅ 算、暗记 ✅ 算（允许无限滚）；**幸运筹码改币 ❌ 不算 —— 倍率照常按反面归零**（遗物只保牌效、不保连胜，2026-10-16 用户拍板；徽章显示「反」） |
| 归零 | 掷出反面**立刻**归零；**战斗内跨回合保留**；战斗结束时清空 |
| 兑现清空 | 「风头正盛」牌**结算后**清空回 1.0（该牌自己吃满倍率）；唯一例外：「追数」击杀时保留 |
| 乘哪些数值 | **伤害 / 格挡 / 金币**（卡面预览实时跟随）；**向上取整**；**不设上限** |
| 词条互斥 | 「风头正盛」牌**不能**同时带「赌博」 |
| 定价 | **裸值按同费常规牌水平**（x1.0 时不亏），倍率是纯奖励层 |
| 显示 | 角色**头顶浮动徽章**，纯文字 `x2.5`（美术后补） |

**已知风险（用户已明确接受，勿再劝阻）**：金币 × 倍率 + 不设上限 + 赌神可无限滚 → 理论上可无限刷金币（而金币**跨战斗永久**），经济可被击穿。用户选择不封顶。另：**裸值按同费常规牌水平** 意味着这 10 张牌"不赌也不亏、赌赢就是白赚"，卡池整体强度随之上移。

### 2.9 四轴引擎（v1.9，对标原版角色的机制浓度）

**问题（v1.8 体检结论）**：赌徒全池围绕**一条**循环（花钱→掷币→兑现）——赌博 18% + 风头 15% + 金币费 42% 高度重叠；对照原版「亡灵契约师」的四条并行轴（奥斯提 26% / 灾厄 13% / 灵魂 11% / 虚无 9%），画风"宽而深"，赌徒"窄而密"，构筑分叉少。

**解法**：把赌徒拆成四条**各自拥有资源、生成、兑现、放大**的引擎；`赌博` 从主轴降级为**通用投递方式**（任何轴的牌都能挂赌博），`风头正盛` 成为轴③的兑现端。

| 轴 | 核心资源 | 生成（怎么攒） | 兑现（怎么花） | 放大 / 防守 | 目标占比 |
|---|---|---|---|---|---|
| ① 金币流水 | 金币 / 本回合花费 | 即时产金 10 + 击杀产金 5 + 引擎产金 3 | 花费追踪转伤害/格挡/抽牌（4 张）、持有量转能量（加码）、保本/晒冷 | 利滚利 / 台规 / 返水 | ~28% |
| ② 出千·确定性 | **必正次数**（可攒的确定性） | 暗记 / 手气正旺 / 赌神 / 出千 / 封口 / 千王 / 偷天换日 / 瞒天过海 | **收网**（一次性换成伤害） | 手气正旺（期望放大）/ 赌神（终极确定性） | ~12% |
| ③ 气势·倍率 | 倍率 | 每次掷出正面（叠码 / 倍投注入） | 风头正盛 10 张兑现牌 | 追数（击杀续风）/ 风头正盛牌本身 | ~19% |
| ④ 赌命·下注 | 生命（已失去生命） | 放血 / 押宝 / 抵押 / 割肉（分红＝金币买血续航） | 赌命（血线大炮） | **押注**（伤害按已失去生命加成） | ~13% |

**设计红线（四轴必须互相独立）**：
1. 每轴至少 1 张**生成器**、1 张**兑现器**——只给增益不给出口的卡不算一条轴；
2. 轴与轴之间只允许"轻度协同"，不允许"缺了另一轴就不可用"（例：押注要能只靠自伤牌成型，不能要求先有金币）；
3. 赌博仍是签名词条，但**不再是资源本身**——它只决定"这一次结算的结果"，不再独自承载整个池子的强度；
4. 中立填充（基础攻击/格挡/抽牌/通用 debuff）保持 ~30%，避免四条轴彼此挤占。

## 7. 经济数值基准与平衡旋钮

### 7.1 收入侧参考（原版）

| 来源 | 数值 |
|---|---|
| 起始金币 | 99 |
| 普怪胜利 | 10-20 |
| 精英 | 35-45 |
| Boss | 100 |
| 删卡 | 75 起，+25/次 |
| 金印（换算锚点） | 3 金 = 1 能量，每回合限 1 次 |

### 7.2 赌徒的战斗现金流（目标画像：小幅盈利）

| 阶段 | 支出预期/场 | 产金预期/场 | 净额 |
|---|---|---|---|
| 第一幕（白卡期） | 15-30 | 10-25（卡产金）+ 奖励 15 | ≈ 0 至微亏 |
| 第二幕（3-5 张产金/双费成型） | 30-45 | 35-55 | +5~10 |
| 第三幕（引擎落地） | 40-60 | 50-75 | +5~15 |

原则：**想富必须多带产金少带双费（牺牲战斗强度），想赢战斗就得把钱花回去**。盈余永远追不上同层精英奖励的量级，防止经济滚雪球。

### 7.3 平衡旋钮清单（调平衡时动的第一批螺丝）

1. 初始遗物改币价格（当前 5）——最敏感的旋钮，直接决定**单张赌博牌的**等效确定性（注意：2026-10-16 起改币**不再保住风头倍率**，所以它买的是牌面、不是连胜）。
2. 统一金币汇率（当前 2.1 伤/金、2.5 挡/金；能量↔金币换算 1 能量 = 7 金币）——动它会同时平移全部双费卡定价。
3. 即时产金量级（当前单张 5-18）与引擎型产金节奏（3-5/回合 + 正面触发）。
4. 手气正旺 / 赌神的获取难度与数值上限（正面率加法上限 75%）。
5. 梭哈的 X 金币系数（当前 10×X，爆发上限的主要阀门）。
6. **四轴配比（v1.9）**：金币 ~28% / 出千 ~12% / 气势 ~19% / 赌命 ~13%——某条轴过强或过弱时，先动该轴的**兑现器**（收网每层伤害、赌命血线系数、押注百分比），不要动生成器（会连带动牌量）。
7. **倍率成长步长（当前 +0.5/次正面）与「风头正盛」牌裸值**——动它会平移全部 12 张倍率关联牌的强度；倍率**不设上限**（含金币）已定，经济风险已接受（见 §2.8）。
